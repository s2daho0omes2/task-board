# خطة مبيعات ينبع 1 — نسخة الرابط المشترك

صفحة واحدة تُنشر على GitHub Pages، وتحفظ تعديلات الجميع في Google Sheet عبر Google Apps Script.

**النتيجة:** رابط عام، أي أحد يفتحه يشوف آخر نسخة، وأي أحد يعدّل عليها يصل تعديله للباقين خلال ثوانٍ.

---

## قبل ما تبدأ

| | |
|---|---|
| **التكلفة** | صفر — GitHub Pages و Google Apps Script مجانيان |
| **الحسابات المطلوبة** | حساب GitHub + حساب Google (اللي عندك) |
| **الوقت** | ١٥ دقيقة، مرة واحدة |
| **مفتاح Anthropic** | **غير مطلوب إطلاقاً** — ولا تضعه في هذه الملفات |

> ⚠️ **تحذير أمني:** لا تضع أي مفتاح API لأنثروبيك (أو غيرها) داخل `index.html`. الصفحة نصّها مكشوف لكل من يفتح الرابط، والمفتاح يُسرق ويُستهلك على حسابك.

---

## الخطوة ١ — أنشئ Google Sheet

1. افتح [sheets.new](https://sheets.new) — يُنشأ جدول جديد فارغ
2. سمّه مثلاً `بيانات خطة ينبع 1`
3. اتركه مفتوحاً

---

## الخطوة ٢ — الصق كود الـ API

1. من داخل نفس الجدول: **الإضافات (Extensions)** ← **Apps Script**
2. امسح كل الكود الموجود في المحرّر
3. افتح ملف `apps-script/Code.gs` من هذه الحزمة، وانسخ محتواه كاملاً والصقه
4. احفظ (Ctrl+S أو ⌘S)

---

## الخطوة ٣ — انشر الـ API

1. في أعلى يمين محرر Apps Script: **Deploy** ← **New deployment**
2. اضغط أيقونة الترس ⚙ بجانب "Select type" واختر **Web app**
3. اضبط الحقول:
   - **Description:** `plan api`
   - **Execute as:** `Me`
   - **Who has access:** `Anyone` ← **مهم جداً**، بدونها لن تعمل الصفحة
4. **Deploy**
5. سيطلب صلاحيات أول مرة: **Authorize access** ← اختر حسابك ← إن ظهر تحذير: **Advanced** ← **Go to … (unsafe)** ← **Allow**
   *(هذا التحذير طبيعي لأنك تشغّل سكربتك الخاص وليس تطبيقاً منشوراً)*
6. **انسخ الرابط** الظاهر تحت **Web app URL** — يبدأ بـ:
   ```
   https://script.google.com/macros/s/AKfy..../exec
   ```

---

## الخطوة ٤ — اربط الصفحة بالـ API

افتح `index.html` بأي محرر نصوص، وفي أول سطور الملف ستجد:

```js
window.PLAN_API_URL = "";
```

الصق الرابط بين علامتي التنصيص:

```js
window.PLAN_API_URL = "https://script.google.com/macros/s/AKfy..../exec";
```

احفظ الملف.

---

## الخطوة ٥ — انشر على GitHub Pages

1. أنشئ مستودعاً جديداً (Repository) — سمّه مثلاً `yanbu1-plan`
   - اجعله **Public** (مطلوب لتفعيل Pages مجاناً)
2. ارفع ملف `index.html` إلى جذر المستودع (Add file ← Upload files)
3. **Settings** ← **Pages** (في القائمة اليسرى)
4. تحت **Source** اختر `Deploy from a branch`
5. تحت **Branch** اختر `main` والمجلد `/ (root)` ← **Save**
6. انتظر دقيقة إلى دقيقتين، ثم حدّث الصفحة — سيظهر رابطك:
   ```
   https://<اسم-حسابك>.github.io/yanbu1-plan/
   ```

**هذا هو الرابط الذي ترسله للجميع.**

---

## كيف تعرف أنها تعمل؟

افتح الرابط وانظر إلى **الشارة أسفل يسار الصفحة**:

| الشارة | المعنى | ماذا تفعل |
|---|---|---|
| 🟢 **نسخة مشتركة** | كل شيء سليم | لا شيء |
| 🔵 **جارٍ الحفظ… / حُفظ للجميع ✓** | تأكيد بعد كل تعديل | لا شيء |
| 🟡 **حفظ محلي — لم يُضبط رابط الـ API** | نسيت الخطوة ٤ | الصق الرابط في `index.html` وارفعه مجدداً |
| 🟡 **تعذّر الاتصال بالخادم** | `Who has access` ليست `Anyone`، أو الرابط خطأ | أعد الخطوة ٣ |
| 🔵 **وصلت تعديلات جديدة — اضغط للتحديث** | شخص آخر عدّل أثناء عملك | اضغط الشارة |

**اختبار نهائي:** افتح الرابط في متصفحين مختلفين (أو جوال + كمبيوتر)، حرّك مهمة في أحدهما، وانتظر ١٥ ثانية — يجب أن تنتقل في الآخر.

---

## أشياء تحتاج تعرفها

**من يعدّل؟** حالياً: أي أحد عنده الرابط. لتقييده لاحقاً — في `Code.gs` ضع كلمة في `PASSCODE`، وأضف في `index.html` سطراً بعد `PLAN_API_URL`:
```js
window.PLAN_EDIT_CODE = "نفس-الكلمة";
```

**التزامن:** الصفحة تسحب آخر نسخة كل ١٥ ثانية. لو عدّلتم في نفس اللحظة، آخر حفظ يفوز، والباقي يشوف «وصلت تعديلات جديدة».

**النسخ الاحتياطي:** كل التعديلات في الخلية `D2` من ورقة `plan` في جدولك. انسخها واحفظها في ملف قبل أي تغيير كبير. ولإرجاع كل شيء للأصل: من محرر Apps Script شغّل الدالة `resetPlan`.

**حدود الحجم:** حتى ٤٥ ألف حرف — يكفي لمئات المهام. لو تجاوزتها ستظهر رسالة `too_large`.

**تحديث التصميم لاحقاً:** لو طوّرنا الصفحة، ترفع `index.html` الجديد فقط. البيانات في الشيت لا تتأثر — لكن **لا تنسَ لصق `PLAN_API_URL` في الملف الجديد**.

**بعد أي تعديل على `Code.gs`:** لازم **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. بدونها يبقى الرابط يشغّل النسخة القديمة.
